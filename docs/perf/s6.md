# S6 stereo frame budget (calibration scene)

Local frame-budget record for the S6 Unity stereo path. The S6 acceptance
budget is **≤ 11.1 ms per frame at 90 Hz** (ADR-0010). These are local
measurements with the committed calibration scene, not the S7 content load; the
nightly lanes still produce the raw regression numbers (see
[`README.md`](README.md)).

- **Date:** 2026-10-02
- **Scene:** `unity/Cubeglass/Assets/Scenes/Calibration.unity` (committed; never
  regenerated by the per-commit lanes)
- **Machine:** AMD Ryzen AI 9 365 (20 logical CPUs, 2.0 GHz base), 23 GiB RAM,
  NVIDIA GeForce RTX 5070 Laptop GPU (7.9 GB), Windows 11 10.0.26200
- **Toolchain:** Unity 6000.6.3f1, Direct3D 12 (level 12.2), PlayMode CLI lane
  (`unity test unity/Cubeglass --mode PlayMode --non-interactive`)
- **Test:** `FrameBudgetPlayModeTests.CalibrationSceneHoldsTheFrameBudgetWithTheOverlayOn`
  (PlayMode suite, 5 tests total)

## Method

The measurement runs in the committed calibration scene with the
`DebugOverlay` **on** (visible). It creates one 3840×1080 side-by-side
`RenderTexture` (**1920×1080 per eye**), points both eye cameras at it, warms up
32 frames, then measures 600 frames. Each measured frame calls
`Camera.Render()` once per eye — the CLI PlayMode lane has no Game View, so the
same `Camera.onPreCull` late-latch path a real frame uses is driven explicitly
(see the T3 handoff note). Frame time is the wall time of the two eye renders
(`Stopwatch`, both eyes = one stereo frame); p50/p95/p99 are nearest-rank over
the 600 samples. The full report (including the machine fields reported by
`SystemInfo`) is written to `%TEMP%\s6-frame-budget.json` by the test.

## Result

| Statistic | Frame time (ms) |
| --- | ---: |
| mean | 0.359 |
| p50 | 0.333 |
| p95 | 0.474 |
| p99 | 0.541 |
| min | 0.289 |
| max | 0.935 |

The observed headroom against the ≤ 11.1 ms budget is large: the mean is 30.9×
inside the budget and even the p99 is 20.5× inside it. The S6 budget passes on
this tree with no tuning required.

## Caveats

- The calibration scene is a **light synthetic load**: ~50 unlit primitives
  (floor grid, axis cubes, wall markers, horizon strip), the stereo rig and the
  IMGUI overlay. It is deliberately not representative of the S7 voxel content
  load, and these numbers must not be quoted for S7.
- The measured value is the **CPU-side render-submission time** of one stereo
  frame in the headless lane; GPU completion, Game View presentation and the
  IMGUI paint pass are not fully represented in that number. The display-side
  behaviour on the glasses (90 Hz cadence, SBS presentation, U-09 FOV and
  distortion) is the S6 HIL run in
  [`../questions/S6-HIL.md`](../questions/S6-HIL.md).
- No absolute timing assertion is enforced in CI; the test records the numbers
  and only fails if the scene cannot be loaded or rendered.

